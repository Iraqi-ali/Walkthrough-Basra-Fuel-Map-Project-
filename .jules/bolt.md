## 2024-10-18 - Debouncing synchronous DOM and Leaflet regenerations
**Learning:** The `applyFilters` function, which is called on every keystroke during station search, explicitly calls `renderStationsList()` and `renderMapMarkers()`. By tracing those functions, I explicitly confirmed that `renderStationsList` synchronously clears and rebuilds the DOM station list (`DOM.stationsList.innerHTML = ''`), and `renderMapMarkers` explicitly clears Leaflet map layers (`appState.markersGroup.clearLayers()`). Triggering these on every `input` keystroke causes unnecessary main-thread blocking during text entry.
**Action:** Implemented a `debounce` utility to wrap high-frequency event listeners (like search `input`) while preserving `this` context via `func.apply(this, args)`. I wrapped the specific listener instead of the core `applyFilters` function to ensure other triggers (like product filter button clicks) remain instantaneous.
