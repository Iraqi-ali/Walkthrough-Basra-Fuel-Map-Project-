## 2026-11-08 - Secure Path Handling in SimpleHTTPRequestHandler
**Vulnerability:** The application was vulnerable to source code disclosure and path traversal because `SimpleHTTPRequestHandler` serves all files by default, and `do_GET` did not restrict access to `.py` or internal `.json` files, allowing attackers to download the server source code.
**Learning:** Implementing path restrictions requires correctly handling edge cases in `urllib.parse.urlparse` (like paths starting with `//` being parsed as network locations) and avoiding query string splitting (`.split("?")[0]`) which creates parser differentials (e.g. bypasses using `#`). Also, `do_HEAD` must be overridden alongside `do_GET` to prevent attackers from probing file existence.
**Prevention:** Use `urllib.parse.urlparse` to extract the path securely, unquote it, normalize it with `posixpath.normpath()`, enforce a leading slash, and convert to lowercase before applying strict allowlists/blocklists. Always override both `do_GET` and `do_HEAD`.
