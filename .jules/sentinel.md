## 2026-07-12 - Fix Path Traversal in SimpleHTTPRequestHandler
**Vulnerability:** The `server.py` implementation used `SimpleHTTPRequestHandler` without adequately filtering requests, allowing path traversal (e.g., `/%2e%2e/etc/passwd`) and direct access to sensitive backend files like `.env`, `server.py`, and `reports.json`.
**Learning:** `SimpleHTTPRequestHandler` serves everything in the current directory and subdirectories. While `self.path` is somewhat sanitized by the base handler, it does not prevent all forms of bypass (like URL-encoded dots `/%2e%2e/` or multiple slashes `//`) if custom logic relies on basic string matching.
**Prevention:** Always implement a strict blocklist (or allowlist) when overriding `do_GET` or `do_HEAD`. Normalize paths by stripping query parameters, unquoting URL encoding, collapsing multiple slashes, and using `posixpath.normpath` before checking against blocked patterns. Explicitly deny access to `.py`, `.env`, `.git`, and server state files (`reports.json`, `visitors.json`).
