## 2026-09-25 - Prevented Direct Access to Server State and Source
**Vulnerability:** The Python `SimpleHTTPRequestHandler` in `server.py` lacked path validation for `.py` and `.json` files, allowing anyone to download the server's source code (`server.py`), internal database (`data.json`), and runtime state (`reports.json`, `visitors.json`) directly. It was also vulnerable to path traversal (e.g., `/%3F/../server.py` or `/%2e%2e/`) due to missing validation before invoking the super class's handler.
**Learning:** `SimpleHTTPRequestHandler`'s default `do_GET` handles any file in the directory unless explicitly intercepted. Simply checking `self.path` with string methods (like `.endswith()`) is insufficient due to parser differentials and dot-dot-slash sequence resolution.
**Prevention:** Always validate requests using `self.translate_path(self.path)` to accurately resolve the absolute local file path before extracting the filename for blocking, ensuring the validation logic correctly accounts for normalization. Apply this unconditionally in `do_GET` and `do_HEAD` to prevent metadata leakage.
