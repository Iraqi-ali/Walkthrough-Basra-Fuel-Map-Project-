## 2026-11-07 - SimpleHTTPRequestHandler Path Bypass\n**Vulnerability:** Path traversal and blocklist bypass via `GET /server.py#`, `//server.py`, and `HEAD` requests.\n**Learning:** Raw socket requests and URL fragments can bypass naive string-matching path blocklists in Python HTTP servers. Missing `do_HEAD` overrides also leak file metadata.\n**Prevention:** Use `urllib.parse` and `posixpath.normpath` to normalize paths, explicitly enforce leading slashes, collapse double slashes, and override `do_HEAD` alongside `do_GET`.
