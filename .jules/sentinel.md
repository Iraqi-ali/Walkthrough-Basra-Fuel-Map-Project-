## 2025-01-20 - Fix Path Traversal/Access Control Vulnerability in Python SimpleHTTPRequestHandler

**Vulnerability:** The Python `server.py` extends `SimpleHTTPRequestHandler` but acts as an API and static file server. However, it fails to override `do_HEAD` or enforce an explicit blocklist in `do_GET` against path traversal attacks. This allows an attacker to bypass intended access controls (or hit sensitive runtime files) using `../` (e.g. `/%2E%2E/server.py`) or by accessing files directly (e.g. `/reports.json`, `/.env`, etc.).
**Learning:** Relying on `SimpleHTTPRequestHandler` to serve files safely without overriding its default static-serving behavior or applying a robust path-normalization blocklist exposes backend code and sensitive files to direct access or path traversal. Always normalize paths (e.g. using `self.translate_path`) and apply an explicit blocklist in a custom handler before falling back to `super().do_GET()`.
**Prevention:** Implement an explicit blocklist on the fully resolved file path (using `self.translate_path(self.path)` and checking parts against known sensitive files/extensions) instead of relying on raw URI prefixes or the default handler behavior. Apply this blocklist to both `do_GET` and `do_HEAD`.
