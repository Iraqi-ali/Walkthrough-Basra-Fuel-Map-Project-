## 2023-11-04 - Path Traversal & Source Code Disclosure via SimpleHTTPRequestHandler
**Vulnerability:** The Python SimpleHTTPRequestHandler exposed the server source code (server.py) and internal JSON databases (reports.json, visitors.json) to direct download because unhandled paths defaulted to native serving.
**Learning:** SimpleHTTPRequestHandler serves all files in the CWD by default. Delegating unconditionally via super().do_GET() allows unauthenticated access to backend-only files. Simplistic string-matching can be bypassed using query parameters, URL fragments, double slashes, and omitted leading slashes. Overriding do_GET without do_HEAD allows metadata leakage.
**Prevention:** Implement a strict allowlist (or blocklist) before delegating to super().do_GET(). Normalize paths by extracting the path component, URL-decoding, collapsing double slashes, resolving traversals via posixpath.normpath, enforcing a leading slash, and casting to lowercase. Secure both do_GET and do_HEAD.
