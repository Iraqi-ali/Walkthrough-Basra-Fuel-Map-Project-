## 2026-08-08 - Added request blocklist
**Vulnerability:** The Python simple HTTP server allows directory traversal and exposes all files in the current working directory, including backend source code (`server.py`), internal data files (`reports.json`, `visitors.json`), and potentially sensitive `.git`, `.env`, and `.Jules` directories. This is because `SimpleHTTPRequestHandler` serves all files unconditionally unless explicitly handled.
**Learning:** Python `SimpleHTTPRequestHandler` must be explicitly secured when used in production or a semi-production environment, especially when it acts both as an API server and static file server. Path normalization and explicit extension/path blacklists are necessary.
**Prevention:** Always implement a robust request handler that explicitly normalizes requested paths (`urllib.parse.unquote`, `posixpath.normpath`), and checks against a strict blocklist before passing requests to `super().do_GET()` or `super().do_HEAD()`. Do not rely on default file serving behavior in a directory containing source code or data.
