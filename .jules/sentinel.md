## 2026-10-07 - Python SimpleHTTPRequestHandler Path Traversal and Sensitive File Exposure
**Vulnerability:** The custom HTTP server using `http.server.SimpleHTTPRequestHandler` exposed the entire repository directory, allowing attackers to download sensitive backend code (`server.py`), internal databases (`reports.json`, `visitors.json`), and potentially perform path traversal to access hidden files (`.git/config`). `do_HEAD` also remained unpatched, allowing metadata leakage.
**Learning:** Extending `SimpleHTTPRequestHandler` without overriding default static file serving logic leaves the working directory exposed by default. Furthermore, naive path checks on `self.path` are vulnerable to parser differentials (e.g., `/%3f/../` bypasses) which curl will exploit if `--path-as-is` is passed.
**Prevention:** Always implement an explicit allowlist or strict blocklist on `self.translate_path(self.path)` rather than `self.path`, checking components relative to `os.getcwd()` to prevent directory traversal and hidden folder access. Apply validation to both `do_GET` and `do_HEAD` methods.
