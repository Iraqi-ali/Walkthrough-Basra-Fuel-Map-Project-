## 2026-08-25 - Prevent Path Traversal Exfiltration via Blocklist
**Vulnerability:** The `server.py` implementation relies on `http.server.SimpleHTTPRequestHandler` as the default fallback for GET requests but failed to enforce path or extension-based blocklists. This allowed users to download arbitrary files, including server code (`server.py`), reports (`reports.json`), and other sensitive files.
**Learning:** `SimpleHTTPRequestHandler` serves all files in the directory by default. When building APIs that fallback to static file serving, it's critical to implement an explicit blocklist (and ideally an allowlist). The path must be translated via `translate_path` prior to checking to prevent directory traversal bypasses (e.g. `../server.py` or URL encoding). Both `do_GET` and `do_HEAD` must implement the blocklist since `do_HEAD` can leak metadata.
**Prevention:** Always implement an explicit blocklist based on translated/normalized paths when using `SimpleHTTPRequestHandler`, and remember to secure both `do_GET` and `do_HEAD`.
