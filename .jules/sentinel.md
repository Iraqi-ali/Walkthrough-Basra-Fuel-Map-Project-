## 2024-05-27 - [CRITICAL] Prevent Sensitive File Exposure in SimpleHTTPRequestHandler
**Vulnerability:** Python's built-in `SimpleHTTPRequestHandler` serves local files directly to the client. This exposes sensitive backend files (`server.py`, `.env`) and server state data files (`data.json`, `reports.json`, `visitors.json`), as well as restricted directories like `.git` and `__pycache__`.
**Learning:** `SimpleHTTPRequestHandler` provides no default protection against directory traversal or direct file requests within its root. URL path manipulation (e.g., using query parameters `?`, URL encoding `%2f`, double slashes `//`) can bypass simple `if path == "/file"` checks if the path is not properly normalized and decoded before validation.
**Prevention:** Implement a strict path blocklist in `do_GET` and `do_HEAD`. Normalize the path first using `posixpath.normpath` and `urllib.parse.unquote`, split off query parameters and fragments, and block requests containing sensitive file extensions or matching specific file/directory paths.
