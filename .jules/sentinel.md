## 2026-09-26 - Prevent Path Traversal and Sensitive File Exposure in SimpleHTTPRequestHandler
**Vulnerability:** The Python `SimpleHTTPRequestHandler` in `server.py` natively served all files in the current working directory, exposing sensitive application files (e.g., `server.py`, `reports.json`, `.git/`) and allowing path traversal.
**Learning:** URL paths must be decoded before validation. Using `self.path` directly enables bypasses (e.g., `/%73erver.py` or `/%2Egit`), while `self.translate_path(self.path)` normalizes the URL and handles URL decoding natively. Furthermore, using `self.translate_path` returns the absolute local file system path (e.g., `/var/www/.hidden/server.py`), so directory checks like `startswith('.')` must only be applied to the relative path components *within* the server's root directory, not the absolute system path.
**Prevention:** Always use `self.translate_path(self.path)` to normalize paths. To check for hidden or forbidden subdirectories, calculate the `os.path.relpath(local_path, server_root)` and evaluate those relative path components, rather than the absolute path.
