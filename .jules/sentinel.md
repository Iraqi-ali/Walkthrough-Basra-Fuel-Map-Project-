## 2026-08-05 - Fix Path Traversal and Source Code Exposure
**Vulnerability:** The Python `http.server.SimpleHTTPRequestHandler` serves files from the root directory without any restrictions. This allows attackers to easily access the source code (`server.py`), internal data stores (`reports.json`, `visitors.json`), and potentially `.env` or `.git` files, completely compromising the application.
**Learning:** Default HTTP handlers in Python standard library (`http.server`) are inherently insecure for serving production web applications because they serve everything in their working directory, missing default restrictions for sensitive backend files.
**Prevention:** When using `http.server.SimpleHTTPRequestHandler` as a custom API and static file server, always implement an explicit blocklist (or allowlist) check for the requested path, ensuring it is properly URL-decoded, collapsed, and normalized to prevent bypasses via URL encoding or path traversal sequences (`../`).
