## 2026-10-19 - Fix Path Traversal in SimpleHTTPRequestHandler
**Vulnerability:** The default `do_GET` fallback in `SimpleHTTPRequestHandler` without an explicit check or allowlist permits users to read arbitrary files from the server's working directory, including the source code (`server.py`) and potentially up the directory tree using path traversal depending on the version or deployment. The `else: return super().do_GET()` allowed downloading `.py` files.
**Learning:** `SimpleHTTPRequestHandler` serves all files in the current directory and subdirectories by default unless strictly controlled. When building custom APIs on top of it, the default behavior of serving local files must be explicitly restricted. Path checking for `/` must also handle query parameters (e.g. `/?track=1`) because if translated using `self.translate_path()`, `/` resolves to the base directory and fails an exact file allowlist check.
**Prevention:** Implement a strict allowlist using absolute path validation (`os.path.commonpath`) on `self.translate_path(self.path)` before passing the request to `super().do_GET()`. Ensure `self.path` root and query string handlers are explicit.
