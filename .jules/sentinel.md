## 2024-08-03 - Path Traversal & Information Exposure in SimpleHTTPRequestHandler
**Vulnerability:** The `do_GET` fallback to `super().do_GET()` allowed unrestricted access to backend source code (`server.py`) and sensitive state files (`reports.json`, `visitors.json`), and lacked proper path normalization to prevent bypasses.
**Learning:** `SimpleHTTPRequestHandler` serves all files in the current directory by default, requiring an explicit blocklist (and not just an allowlist for dynamic frontend assets) and robust path normalization (handling absolute URIs, collapsing slashes, unquoting, and `posixpath.normpath` with a guaranteed leading slash) to securely restrict access in environments mixing frontend and backend files.
**Prevention:** Always implement a strict blocklist with comprehensive path extraction/normalization (including checking `do_HEAD`) when overriding `SimpleHTTPRequestHandler` in a mixed-content root directory, and do not mutate `self.path` before calling `super().do_GET()` to preserve directory redirects.
