## 2026-07-03 - [Path Traversal in Python HTTP Server]
**Vulnerability:** Path Traversal / Information Exposure. The SimpleHTTPRequestHandler in Python serves all files in the current directory and its subdirectories by default, which exposed sensitive files such as server.py, data.json, reports.json, visitors.json, and the .git/ directory.
**Learning:** urllib.parse.urlparse has a quirk where it interprets paths starting with double slashes (e.g. //data.json) as a network location (netloc) instead of a path. Relying solely on urlparse for path validation can allow attackers to bypass path-based blocklists. Also, when extending SimpleHTTPRequestHandler, overriding both do_GET and do_HEAD is necessary to fully block access to files. Modifying self.path directly can interfere with directory redirects.
**Prevention:** Split the path manually to remove query strings and fragments instead of relying on urlparse. Then use urllib.parse.unquote, collapse multiple slashes, and use posixpath.normpath to normalize the path safely before checking it against a blocklist. Finally, ensure both do_GET and do_HEAD are properly intercepted.
