## 2023-10-22 - Path Traversal in SimpleHTTPRequestHandler
**Vulnerability:** The application used `SimpleHTTPRequestHandler` in `server.py` to serve static files on any path not explicitly caught by the `/api/` endpoints. This allowed unauthenticated path traversal attacks (e.g., `GET /../../../../../etc/passwd`), exposing arbitrary files on the server's file system.
**Learning:** `SimpleHTTPRequestHandler` automatically serves any file on the disk within its working directory and can be tricked if there are no restrictions on the paths it processes, particularly when sub-classed without overriding `do_GET` correctly for unexpected paths.
**Prevention:** Always implement an explicit allowlist or validation check on requested paths, translating them to absolute paths and verifying they match intended static files (like `index.html`, `style.css`) before passing them to the superclass for serving. Make sure to account for query parameters on root paths (e.g., `/?foo=bar`).
