## 2026-11-06 - SimpleHTTPRequestHandler Source Code Disclosure\n**Vulnerability:** The standard `SimpleHTTPRequestHandler` exposed the server script (`server.py`) and data files (`reports.json`, `visitors.json`) to anyone accessing the root path. Bypasses like `//server.py` or URL-encoded variants would also allow access.\n**Learning:** Standard library HTTP handlers like `SimpleHTTPRequestHandler` do not implement path-based blocklists out of the box, defaulting to serving all files in the current directory.\n**Prevention:** Override both `do_GET` and `do_HEAD` with an authorization check. Normalize the path using `urllib.parse.urlparse`, decode it, handle double slashes, and use `posixpath.normpath` before evaluating path rules.\n
