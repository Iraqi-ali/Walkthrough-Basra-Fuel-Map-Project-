## 2026-10-23 - Prevent unauthorized file access in Python HTTP server
**Vulnerability:** The application was serving all files in its directory via `http.server.SimpleHTTPRequestHandler`, which meant that users could download `server.py` or `.json` files, exposing the application's source code and data logic.
**Learning:** `SimpleHTTPRequestHandler` serves the entire current working directory by default. When building a custom API handler on top of it, one must explicitly define an allowlist of files (e.g., `index.html`, `app.js`, `style.css`) and explicitly handle root path requests to avoid exposing sensitive files. Furthermore, it's crucial to resolve paths with `self.translate_path(self.path)` before applying the allowlist to prevent path traversal issues.
**Prevention:** Always restrict access to a specific list of public static files and ensure you properly handle the root endpoint or query parameters when building API servers on top of `SimpleHTTPRequestHandler`.
