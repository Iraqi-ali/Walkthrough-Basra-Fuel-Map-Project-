## 2026-09-09 - Path Traversal Vulnerability in SimpleHTTPRequestHandler Fallback
**Vulnerability:** The Python `SimpleHTTPRequestHandler` fallback was vulnerable to Path Traversal and Arbitrary File Read, allowing access to `server.py`, `data.json`, `.git/config`, etc.
**Learning:** `SimpleHTTPRequestHandler` serves arbitrary files by default if `do_GET` delegates to `super().do_GET()` without intercepting safe paths first. Checking for path prefixes or manually unquoting without iteratively replacing `//` with `/` can allow attackers to bypass simple blocklists.
**Prevention:** Unquote the URL explicitly and strip query/fragment strings. Implement a function to iteratively normalize paths (e.g., replacing `//` with `/`). Always evaluate split segments for hidden file prefixes (e.g., `.`) instead of checking the absolute resolved path to prevent blocking execution entirely if the script is in a hidden parent directory. Explicitly maintain a hardcoded blocklist of core application logic and data files. Apply identical protections on both `do_GET` and `do_HEAD`.
