## 2026-09-12 - Prevent Path Traversal and Sensitive File Exposure
**Vulnerability:** The Python SimpleHTTPRequestHandler allows unrestricted access to source code (.py), internal data (data.json, reports.json, visitors.json), and hidden files (/.git/) via GET and HEAD requests. Additionally, path traversal techniques (e.g. /api/../server.py) and double slash injections (//server.py) could bypass naive blocklists.
**Learning:** Checking the raw request path (`self.path`) against restricted prefixes isn't sufficient because it can be bypassed with traversal sequences or double slashes. Relying on `urllib.parse.urlparse(path).path` is also flawed since `//` prefix parses as a network location. Furthermore, `HEAD` requests leak metadata if only `do_GET` is overridden. Finally, blocking all `.json` files is dangerous and can break the app; block specific sensitive data files instead.
**Prevention:** Always decode and normalize the URL manually (unquote, strip `//`, split `?` and `#`) before checking for blocked specific files (like `data.json`, `reports.json`, `visitors.json`), source extensions (.py), or hidden segments (starting with `.`). Enforce blocklist checks unconditionally in both `do_GET` and `do_HEAD` methods.
