## 2026-10-11 - Adding ARIA labels to dynamically generated interactive elements
**Learning:** This application dynamically injects complex, interactive HTML strings (e.g., station cards and report dialogs) via JavaScript (`app.js`). Icon-only buttons within these injected templates (like report buttons and directions links) lacked `aria-label`s, making them opaque to screen readers. When enhancing accessibility in such apps, it's crucial to inspect both the static HTML (`index.html`) and the dynamic JS templates.
**Action:** When auditing applications that rely heavily on dynamic HTML injection (like Leaflet popups or dynamic list rendering), proactively search JS files for string literals containing interactive elements (`<button>`, `<a>`) to ensure they have proper ARIA attributes, especially when they rely solely on icons (e.g., FontAwesome) for visual context.
