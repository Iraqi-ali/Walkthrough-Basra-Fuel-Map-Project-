## 2026-10-02 - Add ARIA Labels to Interactive Elements

**Learning:** When using icon-only buttons or visually hidden text, it is critical to provide an accessible name for screen reader users via `aria-label`. Without this, screen readers may announce the element as unlabelled, making it difficult for visually impaired users to understand the functionality.
**Action:** Always provide an explicit `aria-label` for elements that lack visible descriptive text.
